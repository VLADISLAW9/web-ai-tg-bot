# Проект: Telegram Bot для ИИ-саммаризации Frontend статей (Personal Reader Bot)

Этот файл является техническим заданием для Claude Code. Бот создается для личного использования одним разработчиком. Цель — автоматизировать поиск актуальных англоязычных публикаций по Frontend-разработке и предоставлять их краткие ИИ-выжимки на русском языке в приватном чате. Для хранения истории используется простой JSON-файл в самом проекте.

---

## Цель проекта

Создать персонального Telegram-вета, который по запросу пользователя («Найти статью») ищет качественные статьи по Frontend-разработке (React, Vue, TypeScript, CSS, Web Vitals и т.д.), извлекает их текстовое содержимое и главное изображение, делает структурированную выжимку (summary) на русском языке с помощью ИИ и отправляет пользователю в чат (Картинка + Саммари + Ссылка на оригинал).

---

## Технологический стек

- **Платформа / Язык:** Node.js (TypeScript).
- **Фреймворк Telegram:** `gramY` (`@grammyjs/bot`).
- **Поиск в интернете:** **Tavily API** или **Jina Search API** (поиск свежих технических статей).
- **Парсинг контента:** **Jina Reader API** (`https://r.jina.ai/`) — для очистки веб-страниц в Markdown и получения URL главной картинки.
- **ИИ (Суммаризация):** **Google Gemini API** (модель `gemini-2.5-flash`) или **OpenAI API** (`gpt-4o-mini`).
- **База данных:** **Локальный JSON-файл** (`data/history.json`) — встроенный модуль Node.js `fs/promises`. Хранит простой массив строк (URL-адресов), которые бот уже показал пользователю, чтобы избежать повторов при следующих запросах.

## Архитектура и Воркфлоу (Как это работает)

1. **Запрос:** Пользователь нажимает текстовую кнопку `Найти статью` или отправляет команду `/find` в приватном чате с ботом.
2. **Безопасность:** Бот проверяет ID пользователя по переменной `ADMIN_TELEGRAM_ID`. Если ID не совпадает — бот игнорирует запрос.
3. **Поиск:** Бот выбирает случайную тему из заготовленного пула (например: _Vite performance, React Server Components, CSS container queries, TypeScript advanced types, Web performance optimization_) и ищет топ-5 статей через API поиска.
4. **Фильтрация:** Бот считывает `data/history.json`, парсит его в массив и сверяет полученные ссылки. Выбирает первую ссылку, которой еще нет в массиве.
5. **Парсинг:** Выбранный URL отправляется в Jina Reader для получения очищенного текста статьи и URL главного изображения.
6. **ИИ-Суммаризация:** Текст статьи передается в LLM. Нейросеть генерирует структурированную выжимку на русском языке по строгому шаблону:
   - **Главная суть:** (1-2 предложения)
   - **Ключевые инсайты:** (3-4 буллит-поинта с техническими деталями)
   - **Кому полезно:** (1 предложение)
   - _Ограничение:_ Выжимка должна быть емкой (до 700 символов), чтобы гарантированно уместиться в лимиты подписи к фото в Telegram.
7. **Ответ и сохранение:** Бот отправляет пользователю сообщение через `ctx.replyWithPhoto` (Картинка + Текст саммари + Ссылка на оригинал) и сразу записывает новый URL в массив в `data/history.json`, сохраняя файл на диск.

## Структура проекта

```text
frontend-digest-bot/
├── src/
│   ├── bot/
│   │   ├── handlers.ts       # Обработка команды /start и кнопки "Найти статью"

│   ├── database/
│   │   └── jsonStore.ts      # Модуль для чтения/записи файла data/history.json
│   ├── config.ts             # Конфигурация (BOT_TOKEN, ADMIN_ID, API_KEYS)
│   └── index.ts              # Точка входа приложения
├── data/
│   └── history.json          # Локальный файл-база (массив отсмотренных URL)

├── claude.md
├── package.json
```
